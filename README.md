# 🍰 JaffaCake

**JaffaCake** is a lightweight, local-only CTF and pentest tracker designed for hackers who want to log machines, track flags, and instantly generate publication-ready HTML write-ups without dealing with bloated software or antivirus false positives.

![Aesthetic](https://img.shields.io/badge/Aesthetic-CRT%20Terminal-00ff66?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

## ✨ Features

- **CRT Terminal Aesthetic:** Dark-mode interface styled with neon green accents (`#00ff66`) that matches professional cybersecurity portfolios.
- **Local-First & Private:** Runs entirely on `127.0.0.1` using a local SQLite database. No cloud accounts, no telemetry, and zero third-party tracking.
- **Structured Note Logging:** Keep track of target IPs, operating systems, credentials, and step-by-step hypotheses.
- **⚡ The Write-Up Exporter:** A built-in feature that transforms your logged machine notes, tasks, and commands into a clean, structured HTML write-up file using standardized meta-boxes, skills grids, and task tables.
- **Zero Antivirus Friction:** Clean, transparent code built from scratch with no obfuscated payloads or reverse-shell signature triggers.
